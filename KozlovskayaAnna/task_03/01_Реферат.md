# Реферат

Данная курсовая работа посвящена разработке полнофункциональной веб-системы управления мероприятиями «Zafid» (Зафичь, идём?), предназначенной для организации и координации событий с участием спикеров, регистрацией участников и распределением билетов. Система реализована по архитектуре «клиент-сервер» с использованием современного стека технологий, включающего Next.js на стороне фронтенда, Node.js с Express на бэкенде и MongoDB в качестве системы управления базой данных.

В рамках работы реализованы основные сущности предметной области: события, пользователи, спикеры, участники, билеты и приглашения. Разработан REST API для взаимодействия клиентской и серверной частей приложения. Реализована ролевая модель доступа с разделением прав между обычными пользователями и администраторами системы. Для обеспечения безопасности применяется механизм аутентификации на основе JWT-токенов с использованием HTTP-only cookies.

Система предоставляет пользователям возможность просмотра списка мероприятий, регистрации на события, получения электронных билетов и приглашения других участников. Административная панель позволяет управлять событиями, спикерами и пользователями через специализированный интерфейс. Реализована валидация данных на клиентской и серверной стороне, обработка ошибок и логирование запросов.

Работа содержит описание постановки задачи, проектирование архитектуры системы, разработку алгоритмов ключевых операций, детальное описание программной реализации и инструкции по развёртыванию приложения.

**Ключевые слова**: управление мероприятиями, веб-приложение, REST API, Node.js, Express, MongoDB, Next.js, React, JWT, аутентификация, ролевая модель, билетная система.
