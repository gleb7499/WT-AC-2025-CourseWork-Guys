Для рисунка 5.4 – Административная панель создания события:
Открыть административную часть приложения
Войти как администратор (email и пароль администратора из базы данных или созданной учётной записи)
Перейти на страницу создания нового события: http://localhost:3000/admin/events/create

На скриншоте должны быть видны:
- Форма создания события со всеми полями:
  - Поле для ввода названия события
  - Поле для загрузки обложки (с превью или кнопкой выбора файла)
  - Текстовый редактор для описания (поддержка Markdown)
  - Поля для выбора даты и времени начала
  - Поля для выбора даты и времени окончания
  - Поле для ввода места проведения
  - Поле для указания вместимости
  - Выбор спикеров (dropdown, мультиселект или список чекбоксов)
- Кнопка для сохранения/создания события
- Административное меню или навигация

Скриншот должен показывать полную форму для создания события.
