# Заключение

В результате выполнения курсовой работы была разработана полнофункциональная веб-система управления мероприятиями «Zafid», предназначенная для автоматизации процессов организации событий, регистрации участников и координации спикеров. Система реализована в соответствии с современными подходами к разработке веб-приложений и соответствует всем критериям приёмки минимально жизнеспособного продукта.

Реализованная система обеспечивает полный цикл работы с мероприятиями: от создания события администратором до регистрации пользователей, получения билетов и отправки приглашений. Архитектура приложения построена по принципу разделения клиентской и серверной частей, что обеспечивает гибкость развёртывания и возможность независимого масштабирования компонентов.

На стороне сервера реализован REST API с использованием Node.js и Express, предоставляющий структурированные endpoint для всех операций системы. Применение Mongoose для работы с MongoDB обеспечило типобезопасность данных и упростило реализацию бизнес-логики. Модульная архитектура серверной части с разделением на модели, контроллеры, маршруты и middleware способствует поддерживаемости кода и облегчает внесение изменений.

Клиентская часть на базе Next.js предоставляет современный адаптивный интерфейс, работающий на различных устройствах. Использование React и компонентного подхода обеспечило переиспользование кода и консистентность пользовательского опыта. Применение Tailwind CSS ускорило разработку интерфейса и обеспечило единый стиль оформления.

Особое внимание уделено вопросам безопасности системы. Реализована надёжная аутентификация на основе JWT-токенов с хранением в HTTP-only cookies, что защищает от атак межсайтового скриптинга. Пароли пользователей хешируются с использованием алгоритма bcrypt перед сохранением в базу данных. Все пользовательские входные данные проходят валидацию на сервере, а контент в формате Markdown санитизируется перед отображением для предотвращения инъекций.

Ролевая модель доступа разделяет функционал между обычными пользователями и администраторами. Обычные пользователи имеют возможность просматривать события, регистрироваться на них, получать билеты и отправлять приглашения. Администраторы получают полный контроль над содержимым системы через специализированную панель управления, позволяющую создавать и редактировать события, управлять спикерами и пользователями.

Реализованная функция приглашений соответствует критерию приёмки MVP и добавляет социальный аспект в систему, позволяя пользователям рекомендовать мероприятия друг другу. Механизмы предотвращения самоприглашений и дублирования обеспечивают корректность работы данной функции.

Система готова к развёртыванию и использованию для организации мероприятий среднего масштаба. Документация по установке и настройке окружения позволяет развернуть приложение как в локальной среде для разработки, так и на продакшн-серверах. Модульная архитектура и использование современных технологий создают основу для дальнейшего развития функциональности.

В качестве направлений дальнейшего развития системы можно выделить следующие возможности: интеграция с платёжными системами для поддержки платных мероприятий, реализация системы уведомлений по электронной почте и push-уведомлений, добавление функционала календаря с возможностью экспорта событий в популярные календарные приложения, внедрение системы отзывов и оценок мероприятий, разработка мобильного приложения для iOS и Android, расширение административной панели с аналитикой посещаемости и статистикой по событиям, реализация многоязычной поддержки интерфейса, добавление функции онлайн-трансляций для гибридных мероприятий.

Разработанная система демонстрирует применимость современного стека веб-технологий для создания функциональных и безопасных приложений, решающих практические задачи автоматизации организационных процессов. Полученный опыт может быть использован для разработки аналогичных систем в смежных областях, требующих управления событиями, пользователями и ресурсами.
