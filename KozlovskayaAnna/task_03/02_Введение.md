# Введение

Современные тенденции цифровизации охватывают все сферы жизни общества, включая организацию и проведение мероприятий различного масштаба и формата. Традиционные методы координации событий с помощью бумажных списков, телефонных звонков и электронной почты становятся неэффективными при работе с большим количеством участников и множественными событиями. Актуальность разработки специализированных информационных систем для управления мероприятиями обусловлена необходимостью автоматизации процессов регистрации участников, контроля вместимости площадок, координации спикеров и отслеживания посещаемости событий [1].

Существующие решения в данной области часто являются избыточными для небольших организаций или локальных сообществ, требуя значительных финансовых затрат и технических компетенций для внедрения и поддержки. В то же время универсальные системы не учитывают специфику отдельных типов мероприятий и не предоставляют гибких механизмов адаптации функциональности под конкретные задачи организаторов.

Данная курсовая работа направлена на создание веб-системы управления мероприятиями, которая сочетает простоту использования с достаточной функциональностью для организации событий среднего масштаба. Система разработана в соответствии с вариантом 15 задания: «Ивенты "Зафичь, идём?"» и ориентирована на решение задачи организации мероприятий без излишней сложности и административного бардака.

**Цель работы**: разработать полнофункциональную веб-систему для управления мероприятиями с поддержкой регистрации участников, управления билетами, координации спикеров и административной панелью для организаторов.

**Задачи работы**:

1. Проанализировать требования к системе управления мероприятиями и определить основные функциональные и нефункциональные характеристики.

2. Спроектировать архитектуру веб-приложения с разделением на клиентскую и серверную части, определить структуру данных и взаимосвязи между сущностями предметной области.

3. Разработать алгоритмы ключевых операций системы, включая регистрацию пользователей, аутентификацию, управление событиями и выдачу билетов.

4. Реализовать серверную часть приложения с использованием Node.js и Express, обеспечив создание REST API для всех операций системы.

5. Реализовать клиентскую часть приложения на базе фреймворка Next.js с адаптивным пользовательским интерфейсом.

6. Разработать ролевую модель доступа с разделением функционала между обычными пользователями и администраторами.

7. Реализовать механизмы безопасности, включая аутентификацию на основе JWT-токенов, валидацию входных данных и защиту от базовых типов атак.

8. Подготовить документацию по развёртыванию и эксплуатации системы.

Разработанная система должна обеспечивать минимально жизнеспособный продукт (MVP) с возможностью управления событиями, билетами, участниками и спикерами, а также реализовывать функцию приглашений как критерий приёмки MVP.
