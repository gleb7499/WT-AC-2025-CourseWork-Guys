# Введение

Современный рынок труда характеризуется высокой динамикой и значительным объёмом информационных потоков между работодателями и соискателями. Эффективное взаимодействие участников рынка труда требует использования специализированных платформ, позволяющих оперативно публиковать вакансии, размещать резюме и осуществлять коммуникацию между заинтересованными сторонами [2].

Актуальность разработки систем поиска работы обусловлена необходимостью снижения временных затрат на подбор персонала и поиск вакансий, повышения прозрачности процессов найма, обеспечения структурированного хранения информации о вакансиях и кандидатах. Традиционные методы размещения объявлений в средствах массовой информации и рассылки резюме по электронной почте уступают место централизованным веб-платформам, предоставляющим удобные инструменты поиска, фильтрации и коммуникации.

Объектом данной курсовой работы является процесс автоматизации взаимодействия работодателей и соискателей в сфере трудоустройства. Предметом исследования выступают методы проектирования и реализации веб-системы для публикации вакансий и управления откликами.

Целью работы является разработка полнофункциональной веб-платформы «Работа мечты», обеспечивающей размещение вакансий, публикацию резюме, подачу откликов и обмен сообщениями между пользователями.

Для достижения поставленной цели необходимо решить следующие задачи:

- провести анализ требований к системе и определить перечень функциональных возможностей минимально жизнеспособного продукта,
- спроектировать архитектуру многоуровневого веб-приложения с разделением клиентской и серверной частей,
- разработать модель данных для хранения информации о пользователях, компаниях, вакансиях, резюме, откликах и сообщениях,
- спроектировать интерфейсы программирования приложений для взаимодействия клиентской и серверной частей,
- реализовать механизмы аутентификации и авторизации пользователей с разграничением прав доступа по ролям,
- разработать пользовательский интерфейс с учётом специфики работы работодателей и соискателей,
- реализовать систему обмена текстовыми сообщениями между участниками платформы,
- осуществить тестирование и документирование разработанной системы.

Вариант курсового проекта соответствует теме «Доска вакансий с функционалом откликов и управления резюме». Минимально жизнеспособный продукт включает управление вакансиями, резюме, откликами и сообщениями. Система предоставляет программные интерфейсы для работы с основными сущностями: Job, Resume, Application, Message, Company, User. Ключевым ограничением проекта является необходимость реализации модерации откликов на этапе приёмки минимально жизнеспособного продукта [3].

Структура пояснительной записки включает постановку задачи, описание разработки алгоритмов обработки данных и аутентификации, детализацию разработки программы с указанием архитектуры и технологий, а также заключение и список использованных источников.
