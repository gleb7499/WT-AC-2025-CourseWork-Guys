# Заключение

В ходе выполнения курсовой работы разработана полнофункциональная веб-система «Работа мечты» для автоматизации взаимодействия работодателей и соискателей на рынке труда. Система обеспечивает публикацию вакансий, размещение резюме, подачу откликов и обмен сообщениями между пользователями.

Проведён анализ требований к системе поиска работы и определён перечень функциональных возможностей минимально жизнеспособного продукта. Спроектирована трёхуровневая архитектура веб-приложения с разделением клиентской части на базе Next.js, серверной части на базе FastAPI и уровня хранения данных на базе SQLite. Разработана модель данных, включающая восемь основных сущностей, связанных внешними ключами для обеспечения целостности информации.

Спроектированы и реализованы двадцать шесть endpoint-ов REST API, обеспечивающих взаимодействие клиента и сервера. Реализованы механизмы аутентификации на основе JWT-токенов и авторизации с разграничением прав доступа по ролям работодателя и соискателя. Пароли пользователей защищены криптографическим хэшированием с использованием алгоритма bcrypt.

Разработан пользовательский интерфейс с применением библиотеки компонентов Material-UI и фреймворка Next.js. Интерфейс адаптирован для двух ролей пользователей: работодатели получают доступ к функциям управления компаниями, публикации вакансий и просмотра откликов, соискатели используют функции создания резюме, поиска вакансий и подачи откликов. Реализована система обмена текстовыми сообщениями, позволяющая участникам платформы вести переговоры после подачи отклика.

Применены современные технологии разработки, включая TypeScript для статической типизации на клиенте, Pydantic для валидации данных на сервере, Zustand для управления состоянием приложения. Асинхронная обработка запросов на сервере обеспечивает производительность при множественных одновременных обращениях. Пагинация списков вакансий и пользователей предотвращает перегрузку интерфейса и снижает объём передаваемых данных.

Выполнено тестирование основных сценариев использования системы: регистрация и авторизация пользователей, создание профилей компаний и резюме, публикация вакансий и подача откликов, обмен сообщениями между участниками. Все критерии приёмки минимально жизнеспособного продукта выполнены. Система корректно разграничивает доступ к функциям в зависимости от роли пользователя и предотвращает несанкционированный доступ к защищённым ресурсам.

Разработанная система может использоваться в учебных и демонстрационных целях для иллюстрации принципов построения современных веб-приложений. Архитектура системы допускает дальнейшее развитие функциональности, включая добавление расширенного поиска вакансий, системы рекомендаций, уведомлений в реальном времени, аналитических функций для работодателей и соискателей.

Перспективы развития системы включают переход на промышленную систему управления базами данных для повышения производительности и масштабируемости, реализацию механизма загрузки файлов резюме, добавление функций рейтинга кандидатов и компаний, интеграцию с внешними сервисами аутентификации, внедрение системы уведомлений на основе WebSocket для мгновенного информирования о новых сообщениях и откликах.

Результаты работы подтверждают возможность создания функциональной платформы для поиска работы с использованием открытых технологий и фреймворков. Приобретённый опыт проектирования и реализации полнофункционального веб-приложения может быть применён при разработке других информационных систем в различных предметных областях.
