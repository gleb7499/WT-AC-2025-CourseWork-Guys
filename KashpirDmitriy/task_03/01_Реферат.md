# Реферат

Данная курсовая работа посвящена проектированию и реализации веб-системы «Работа мечты» — доски вакансий с функционалом управления резюме, откликами и коммуникацией между работодателями и соискателями. Проект выполнен с использованием современных технологий разработки: Next.js на стороне клиента, FastAPI для серверной части и SQLite в качестве системы управления базами данных [1].

В ходе работы были решены следующие задачи: анализ требований к системе поиска работы, разработка архитектуры многоуровневого веб-приложения, проектирование модели данных и API, реализация механизмов аутентификации и авторизации на основе JWT-токенов, создание пользовательского интерфейса с учётом разделения ролей работодателя и соискателя, а также тестирование и документирование системы.

Основной результат работы — функционирующая платформа для публикации вакансий, размещения резюме и взаимодействия участников рынка труда. Система обеспечивает защищённый доступ к данным, поддерживает пагинацию и фильтрацию, предоставляет встроенный чат для общения работодателей с кандидатами.

Реализованные функциональные возможности включают регистрацию и авторизацию пользователей с выбором роли, создание и редактирование профилей компаний и резюме, публикацию вакансий с указанием требований и условий, подачу откликов на вакансии, просмотр списка соискателей для работодателя и обмен текстовыми сообщениями внутри платформы.

Проект демонстрирует применение современных подходов к построению веб-систем, включая разделение фронтенда и бэкенда, использование компонентной архитектуры интерфейса, типизацию данных средствами TypeScript, валидацию входных данных моделями Pydantic и управление состоянием через библиотеку Zustand.

Пояснительная записка содержит описание поставленной задачи, обоснование выбора технологий, детализацию алгоритмов обработки данных и аутентификации, спецификацию API и модели данных, а также инструкцию по развёртыванию и эксплуатации системы.

**Ключевые слова**: доска вакансий, веб-приложение, Next.js, FastAPI, JWT-аутентификация, REST API, SQLite, TypeScript, управление резюме, система откликов, чат работодателя и кандидата.
