Для рисунка 5.1 – Архитектура системы:

Создать диаграмму архитектуры системы, показывающую три основных компонента:
1. Клиентское приложение (React SPA) - браузер пользователя
2. Серверное приложение (Node.js + Express) - REST API
3. База данных (PostgreSQL)

Показать взаимосвязи между компонентами:
- Стрелка от клиента к серверу с надписью "HTTP/HTTPS запросы (JSON)"
- Стрелка от сервера к БД с надписью "Prisma ORM"
- Указать основные технологии для каждого компонента

Можно использовать любой инструмент для создания диаграмм (draw.io, Lucidchart, PlantUML, или нарисовать вручную).

Рекомендуемый формат: PNG, размер около 800x600 пикселей.
