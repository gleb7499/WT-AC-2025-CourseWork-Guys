Для рисунка 1.1 – Диаграмма сущностей (ERD):
Создать диаграмму сущностей, показывающую структуру базы данных системы планирования обучения. На диаграмме должны быть отображены четыре основные таблицы: User (пользователи), Topic (темы), Goal (цели), ProgressEntry (записи прогресса). Указать связи между таблицами: User 1-* Goal (один пользователь может иметь много целей), Topic 1-* Goal (одна тема содержит много целей), Goal 1-* ProgressEntry (одна цель имеет много записей прогресса). Для каждой таблицы указать основные поля и их типы данных.
