# Заключение

В результате выполнения курсового проекта разработано веб-приложение для планирования обучения и трекинга прогресса по темам, соответствующее поставленным требованиям и целям работы.

В ходе работы решены следующие задачи. Спроектирована модель данных для хранения информации о пользователях, темах, целях и записях прогресса с использованием реляционной базы данных PostgreSQL. Модель обеспечивает ссылочную целостность через внешние ключи и эффективный доступ к данным за счёт индексации критичных полей. Разработаны алгоритмы вычисления процента выполнения целей на основе суммирования записей прогресса, генерации агрегированных отчётов с группировкой по темам и пользователям, проверки прав доступа с разграничением по ролям.

Реализована серверная часть приложения на базе Express и TypeScript с использованием Prisma ORM для доступа к данным. Серверное приложение предоставляет REST API для управления всеми сущностями системы с поддержкой операций создания, чтения, обновления и удаления. Внедрена аутентификация на основе JWT-токенов с механизмом автоматического обновления сессии через refresh-токены, обеспечивающая безопасное хранение учётных данных и защиту от несанкционированного доступа. Реализована ролевая модель доступа с разделением прав администратора и обычного пользователя на уровне API.

Создана клиентская часть на базе React и TypeScript с использованием Vite для быстрой разработки. Интерфейс включает страницы регистрации и входа, личный дашборд пользователя с визуализацией прогресса в виде диаграмм, формы для создания и редактирования целей, добавления записей прогресса, административную панель для управления системой. Применена библиотека react-hook-form для управления формами и Zod для валидации данных на клиенте, обеспечивающие удобство использования и предотвращение ввода некорректных данных.

Система обеспечивает автоматическое вычисление прогресса выполнения целей при добавлении записей, генерацию отчётов с агрегированной статистикой по пользователям и темам, визуализацию данных в виде диаграмм для наглядного представления достижений. Разграничение доступа к данным гарантирует, что пользователи работают только со своими целями, в то время как администраторы имеют полный контроль над системой.

Применение современных технологий веб-разработки, таких как TypeScript для статической типизации, Prisma ORM для безопасного доступа к базе данных, JWT для stateless-аутентификации, обеспечивает надёжность, безопасность и удобство сопровождения системы. Модульная архитектура с разделением на клиентскую и серверную части позволяет развивать компоненты независимо и масштабировать систему при росте нагрузки.

Разработанная система прошла проверку по критериям приёмки минимально жизнеспособного продукта. Пользователи могут регистрироваться и аутентифицироваться в системе, работать с целями и записями прогресса, просматривать персональные дашборды с диаграммами. Администраторы управляют пользователями, темами и целями, генерируют отчёты по всей системе. Все функциональные требования реализованы и протестированы.

Подготовлена документация по развёртыванию и эксплуатации системы, включающая инструкции по установке зависимостей, настройке окружения, инициализации базы данных и запуску приложения. Система готова к использованию в локальной среде для планирования учебного процесса и мониторинга прогресса студентов.

Перспективы дальнейшего развития системы включают добавление функциональности напоминаний о дедлайнах с отправкой уведомлений пользователям, внедрение элементов геймификации с системой достижений и рейтингов для повышения мотивации, экспорт данных в форматы для внешнего анализа, разработку мобильного приложения для доступа к системе с портативных устройств, контейнеризацию приложения с использованием Docker для упрощения развёртывания, настройку CI/CD для автоматизации тестирования и деплоя, добавление модуля автоматизированного тестирования для обеспечения качества кода при дальнейшей разработке.

Таким образом, цель работы достигнута: создано функциональное веб-приложение для планирования обучения и трекинга прогресса, обеспечивающее эффективное управление учебными целями и визуализацию достижений.
