# Реферат

Данная пояснительная записка описывает разработку веб-приложения для планирования обучения и трекинга прогресса по темам. Система «До сессии успею» представляет собой полнофункциональное решение для управления учебными целями и мониторинга их достижения.

В работе рассмотрены основные аспекты создания системы: проектирование модели данных, разработка алгоритмов обработки прогресса, реализация клиент-серверной архитектуры с использованием современных веб-технологий. Система построена на базе React для клиентской части и Express с TypeScript для серверной части, с применением PostgreSQL в качестве системы управления базами данных. Реализована ролевая модель доступа с разграничением прав администратора и обычного пользователя.

Функциональность системы включает создание и редактирование учебных тем, формирование персональных целей с указанием целевых значений и дедлайнов, добавление записей о прогрессе выполнения задач, автоматический расчёт процента достижения целей, генерацию отчётов и визуализацию данных в виде диаграмм. Реализована аутентификация пользователей на основе JWT-токенов с поддержкой механизма обновления сессии [1].

Система обеспечивает разграничение доступа к данным на уровне API, гарантируя что пользователи могут работать только со своими целями и прогрессом, в то время как администраторы имеют полный доступ для управления системой. Применены механизмы валидации данных на клиенте и сервере для обеспечения целостности информации.

Пояснительная записка содержит постановку задачи с описанием функциональных и нефункциональных требований, детальное описание разработанных алгоритмов обработки данных, спецификацию программных модулей и API, а также инструкции по развёртыванию и эксплуатации системы.

**Ключевые слова:** веб-приложение, планирование обучения, трекинг прогресса, React, TypeScript, Express, PostgreSQL, REST API, JWT-аутентификация, ролевая модель доступа, диаграммы прогресса, управление целями.
