# Введение

Современное образование требует от студентов умения эффективно планировать учебный процесс и контролировать достижение поставленных целей. В условиях большого объёма учебного материала и множества дисциплин актуальной становится задача систематизации процесса обучения и визуализации прогресса по отдельным темам. Традиционные средства планирования, такие как бумажные планеры или общие приложения для управления задачами, не всегда учитывают специфику образовательного процесса и не предоставляют инструментов для количественной оценки достижений.

Веб-приложения для трекинга прогресса обучения позволяют студентам структурировать свои цели, разбивать их на измеримые этапы и отслеживать динамику продвижения к результату. Визуализация прогресса в виде диаграмм и процентных показателей способствует повышению мотивации и помогает своевременно корректировать учебный план [2]. Централизованное хранение данных и доступность через веб-интерфейс обеспечивают возможность работы с системой с любого устройства.

Целью данной работы является разработка веб-приложения для планирования обучения и трекинга прогресса по темам, обеспечивающего управление учебными целями, фиксацию достижений и визуализацию результатов.

Для достижения поставленной цели необходимо решить следующие задачи:

1. Разработать модель данных для хранения информации о темах, целях, пользователях и записях прогресса с учётом требований целостности и производительности.
2. Спроектировать алгоритмы вычисления процента выполнения целей на основе накопленных записей прогресса и обеспечения корректности расчётов.
3. Реализовать серверную часть приложения на базе Express с поддержкой REST API для управления сущностями системы и разграничения доступа по ролям.
4. Создать клиентскую часть на базе React с интерактивными формами для работы с данными и визуализацией прогресса в виде диаграмм.
5. Внедрить механизм аутентификации и авторизации пользователей с использованием JWT-токенов для обеспечения безопасности данных.
6. Обеспечить ролевую модель доступа с разделением прав администратора и обычного пользователя для управления системой.
7. Разработать инструкции по развёртыванию и эксплуатации системы в локальной среде.

Разрабатываемая система соответствует варианту 14 «Прогресс «До сессии успею»», тема проекта — сервис планирования обучения и трекинга прогресса по темам. Минимально жизнеспособный продукт включает управление темами, целями, записями прогресса и генерацию отчётов. Система предоставляет REST API с эндпоинтами для работы с темами, целями, прогрессом и отчётами. Основные сущности данных: Topic (тема), Goal (цель), ProgressEntry (запись прогресса), User (пользователь). В качестве критерия приёмки выступает корректное создание и отображение диаграмм прогресса на основе реальных данных пользователей.
