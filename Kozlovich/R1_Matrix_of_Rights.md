# Вариант 11 — Матрица прав (операция × роль)

Операции: Просмотр проектов, Создать/Редактировать/Удалить Project, Просмотр багов, Создать Bug, Редактировать Bug, Удалить Bug, Назначить Bug, Изменить статус, Добавить комментарий, Добавить вложение, Управление пользователями.

Роли: Администратор, Менеджер, Разработчик, Пользователь (Reporter)

Таблица (кто может что)

- Просмотр проектов: Администратор, Менеджер, Разработчик, Пользователь
- Создать Project: Администратор
- Редактировать Project: Администратор, Менеджер (свои)
- Удалить Project: Администратор
- Просмотр багов: Администратор, Менеджер, Разработчик, Пользователь (публичные)
- Создать Bug: Администратор, Менеджер, Разработчик, Пользователь
- Редактировать Bug: Администратор, Менеджер, Разработчик (свои), Автор (свои)
- Удалить Bug: Администратор, Менеджер (в своих проектах)
- Назначить Bug: Администратор, Менеджер
- Изменить статус: Администратор, Менеджер, Разработчик (назначенные), Автор (ограниченно)
- Добавить комментарий: Администратор, Менеджер, Разработчик, Пользователь
- Добавить вложение: Администратор, Менеджер, Разработчик, Пользователь
- Управление пользователями: Администратор

Примечания:

- По умолчанию пользователь видит только публичные проекты и баги, к которым имеет доступ (scope ограничение).
- Некоторые операции (например, удаление Bug) могут быть ограничены политикой: только Администратор или Менеджер проекта.
