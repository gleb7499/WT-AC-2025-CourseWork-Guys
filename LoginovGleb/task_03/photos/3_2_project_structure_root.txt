Для рисунка 3.2 – Структура монорепозитория проекта:
Открыть проект в VS Code (или другом IDE), в проводнике файлов раскрыть корневую структуру.
Сделать скриншот так, чтобы были видны основные каталоги и файлы верхнего уровня.
Рекомендуемый состав, который должен попасть в кадр:
- папка apps/ (с раскрытием apps/server и apps/web);
- папка packages/ (с раскрытием packages/ui и packages/utils);
- файлы конфигурации монорепозитория (например, package.json, pnpm-workspace.yaml, lock-файл);
- (по возможности) папка k8s/ и docker-compose файлы.
Скриншот обрезать так, чтобы не было видны личные пути ОС и лишние элементы интерфейса (оставить только дерево проекта и, при необходимости, заголовок окна).
