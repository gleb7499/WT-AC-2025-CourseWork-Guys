Для рисунка 3.1 – Общая архитектура системы обработки заявок:
Сделать простую иллюстрацию (допускается скриншот из draw.io/PowerPoint/Excalidraw) с компонентами и направлениями обмена:
1) «Web-клиент (браузер, SPA)».
2) «Backend API (HTTP, REST)».
3) «PostgreSQL (основные данные: пользователи, заявки, формы, статусы, история)».
4) «Redis (кэш)».
5) «Файловое хранилище uploads/ (вложения)».

На схеме указать, что аутентификация выполняется через JWT access (Bearer) и refresh-cookie (только подписью, без деталей реализации).
