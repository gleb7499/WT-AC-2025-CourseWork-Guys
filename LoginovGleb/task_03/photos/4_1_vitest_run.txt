Для рисунка 4.1 – Пример запуска тестов серверной части (Vitest):
Открыть терминал в корне проекта и выполнить команду запуска тестов серверной части (unit/integration), принятую в проекте.

Рекомендуемые варианты:
1) pnpm --filter @app/server test
2) pnpm --filter @app/server test -- --reporter=dot --silent
3) pnpm --filter @app/server test -- --reporter=basic --silent

Примечание: в проекте в скрипте `test` серверной части уже используется `vitest run`, поэтому дополнительный флаг `--run` указывать не требуется.

Сделать скриншот результата выполнения команды.
На скриншоте должны быть видны:
- команда запуска тестов;
- краткий итог Vitest (количество тестов, passed/failed, время выполнения);
- отсутствие ошибок (в случае успешного прохождения).
