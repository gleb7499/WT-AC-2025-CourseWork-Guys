Для рисунка 3.1 – Архитектура системы:

Создать диаграмму трёхзвенной архитектуры системы, показывающую:

1. Уровень представления (Client Layer):
   - Веб-браузер
   - React SPA (Single Page Application)
   - Компоненты пользовательского интерфейса

2. Уровень бизнес-логики (Application Layer):
   - Express.js сервер
   - REST API endpoints
   - Middleware (аутентификация, авторизация, валидация)
   - Сервисы бизнес-логики
   - Prisma ORM

3. Уровень хранения данных (Data Layer):
   - PostgreSQL база данных
   - Таблицы: users, rooms, bookings, refresh_tokens, audit_logs

Стрелки взаимодействия:
- HTTP/HTTPS запросы между клиентом и сервером (JSON)
- SQL запросы между сервером (через Prisma) и базой данных

Диаграмму можно создать в draw.io, Lucidchart или любом другом инструменте для создания архитектурных диаграмм. Должна быть видна чёткая граница между уровнями и направление потока данных.
