# Реферат

Настоящая работа посвящена проектированию и разработке информационной системы управления бронированием аудиторий «Не занято?». В работе рассмотрены основные требования к системе, описана архитектура клиент-серверного приложения, приведена спецификация программного интерфейса приложения, разработаны алгоритмы обработки данных и предотвращения конфликтов бронирования.

Система реализована в виде одностраничного веб-приложения с использованием технологий React и Vite на клиентской части, Express и PostgreSQL с применением Prisma ORM на серверной стороне. Реализован механизм аутентификации и авторизации на основе токенов JWT, обеспечена ролевая модель доступа для трёх типов пользователей: студентов, преподавателей и администраторов.

В ходе работы спроектирована модель данных, включающая сущности пользователей, аудиторий, бронирований, токенов обновления и журнала аудита. Разработаны алгоритмы проверки временных конфликтов при создании и переносе бронирований, реализована валидация входных данных на основе библиотеки Zod. Применены средства обеспечения безопасности, включая хеширование паролей с использованием bcrypt, защиту HTTP-заголовков посредством Helmet, настройку политик CORS.

Результатом работы является функционирующее приложение, удовлетворяющее требованиям минимально жизнеспособного продукта. Система позволяет пользователям просматривать расписание аудиторий, создавать бронирования с учётом ограничений по длительности в зависимости от роли, отменять и переносить бронирования в рамках прав доступа. Администратор получает возможность управления пользователями и аудиториями, а также просмотра статистики использования ресурсов.

**Ключевые слова**: бронирование аудиторий, веб-приложение, REST API, React, Express, PostgreSQL, Prisma, JWT, аутентификация, авторизация, проверка конфликтов, расписание
