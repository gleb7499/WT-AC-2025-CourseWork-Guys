# Заключение

В ходе выполнения курсовой работы разработано полнофункциональное веб-приложение «Агрегатор новостей "Без фейков"», реализующее комплексную систему управления новостным контентом с механизмами модерации и ролевого разграничения доступа.

Проведён детальный анализ предметной области агрегации новостей, на основании которого сформулированы функциональные требования к системе, определён состав сущностей данных и их взаимосвязи. Разработана архитектура приложения, следующая принципам разделения ответственности между клиентской и серверной частями с взаимодействием через RESTful API. Спроектирована реляционная модель данных с семью основными таблицами и чётко определёнными ограничениями целостности.

Реализована серверная часть на платформе Node.js с использованием фреймворка Express, обеспечивающая обработку HTTP-запросов, валидацию входных данных через библиотеку Zod, взаимодействие с базой данных PostgreSQL посредством ORM Prisma. Интегрированы механизмы безопасности включая хеширование паролей через bcrypt, аутентификацию на основе JWT-токенов с механизмом обновления, настройку защитных HTTP-заголовков через Helmet, конфигурацию CORS для ограничения доступа к API.

Разработана клиентская часть на базе библиотеки React с применением TypeScript, реализующая интуитивный пользовательский интерфейс для всех сценариев использования системы. Внедрено управление состоянием через Zustand, маршрутизация на стороне клиента через React Router, централизованное взаимодействие с API через Axios с перехватчиками для автоматического добавления токенов аутентификации.

Создана гибкая ролевая модель с тремя уровнями доступа, обеспечивающая дифференцированный доступ к функциональности: обычные пользователи могут просматривать ленту новостей с применением фильтров, управлять персональным избранным и подавать жалобы на сомнительный контент; модераторы получают доступ к панели рассмотрения жалоб с возможностью изменения статуса и удаления статей; администраторы обладают полным контролем над системой включая управление пользователями, источниками и тегами.

Реализованы ключевые алгоритмы системы: формирование ленты новостей с поддержкой фильтрации по тегам и источникам, упорядочиванием по времени публикации и пагинацией результатов; управление избранным с проверкой уникальности и контролем принадлежности; обработка жалоб с возможностью изменения статуса и принятия модерационных решений; аутентификация пользователей с генерацией пары токенов и механизмом безопасного обновления.

Подготовлена детальная документация архитектуры, спецификация API с описанием всех endpoints, параметров запросов и структур ответов, инструкции по развёртыванию и запуску приложения в локальном окружении и через Docker Compose. Реализован механизм заполнения базы данных тестовыми данными для демонстрации функциональности системы.

Тестирование разработанного приложения подтвердило соответствие всем критериям приёмки MVP: пользователи успешно аутентифицируются и получают доступ к соответствующей функциональности согласно назначенной роли, фильтрация ленты по тегам и источникам работает корректно, операции управления избранным выполняются без ошибок, процесс создания и рассмотрения жалоб функционирует согласно спецификации, административные операции управления источниками и тегами доступны только пользователям с соответствующими правами.

Система демонстрирует стабильную работу при типовых нагрузках, корректно обрабатывает ошибочные входные данные с возвратом информативных сообщений, обеспечивает защиту от несанкционированного доступа через механизмы аутентификации и авторизации. Архитектура приложения обеспечивает возможность дальнейшего расширения функциональности без существенных изменений базовой структуры.

Разработанное приложение может служить основой для создания полноценного новостного агрегатора с добавлением дополнительных возможностей таких как автоматический сбор контента от внешних источников, полнотекстовый поиск по статьям, система уведомлений, аналитика популярности материалов, персонализированные рекомендации на основе предпочтений пользователей.

Таким образом, поставленные цели и задачи курсовой работы полностью достигнуты. Получен практический опыт проектирования и разработки современных веб-приложений с использованием актуального технологического стека, применения принципов безопасной разработки, работы с реляционными базами данных и построения REST API. Созданный программный продукт соответствует современным стандартам веб-разработки и может быть использован в образовательных и демонстрационных целях.
