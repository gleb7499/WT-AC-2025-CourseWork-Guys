# **Заключение**

В ходе выполнения курсового проекта разработано полнофункциональное веб-приложение для агрегации новостей «Без фейков» с системой модерации жалоб. Реализованная система полностью соответствует требованиям варианта 37 и обеспечивает выполнение всех критериев приёмки MVP.

**Достигнутые результаты:**

1. **Проанализирована предметная область** агрегации новостей и сформулированы функциональные и нефункциональные требования к системе. Определены основные сущности (Source, Article, Tag, Favorite, Report, User) и связи между ними.

2. **Разработана модель данных** на основе реляционной СУБД PostgreSQL с использованием современного ORM Prisma. Модель обеспечивает целостность данных через систему внешних ключей и ограничений, а также оптимизирована с помощью индексов для повышения производительности запросов.

3. **Спроектированы алгоритмы** работы основных компонентов системы: формирования ленты новостей с фильтрацией, обработки жалоб и модерации, управления избранным, аутентификации и авторизации на основе JWT-токенов.

4. **Реализована трёхзвенная архитектура** с чётким разделением на презентационный уровень (React SPA), логический уровень (Node.js + Express REST API) и уровень данных (PostgreSQL). Такое разделение обеспечивает масштабируемость, сопровождаемость и возможность независимой разработки компонентов.

5. **Разработана серверная часть** приложения с использованием Node.js и Express, включающая модульную структуру с разделением на routes, controllers, services, middleware. Реализована валидация входных данных с помощью Zod, логирование с использованием Winston, защита HTTP-заголовков через Helmet.

6. **Создана клиентская часть** на базе React 18 с TypeScript, обеспечивающая интуитивно понятный и отзывчивый интерфейс пользователя. Использование Zustand для управления состоянием и React Router для навигации позволило создать производительное одностраничное приложение.

7. **Реализована ролевая модель доступа (RBAC)** с тремя типами пользователей: администратор (полный контроль над системой), модератор (рассмотрение жалоб и удаление контента), обычный пользователь (просмотр ленты, работа с избранным, подача жалоб). Система корректно ограничивает доступ к функциям в соответствии с ролью.

8. **Реализован полный функционал работы с новостной лентой**, включающий просмотр статей, фильтрацию по тегам и источникам, пагинацию, просмотр детальной информации о статье.

9. **Разработана система модерации жалоб** (критерий приёмки MVP), позволяющая пользователям сообщать о недостоверном контенте, а модераторам рассматривать жалобы и принимать решения об удалении статей. Система обеспечивает полный жизненный цикл жалобы от создания до закрытия.

10. **Проведено комплексное тестирование** системы, охватывающее функциональные требования, безопасность и права доступа. Все 56 тестовых сценариев успешно пройдены, что подтверждает корректность работы системы и соответствие требованиям.

**Практическая значимость:**

Разработанная система может быть использована в качестве базы для создания реальных сервисов агрегации новостей с функционалом контроля качества контента. Модульная архитектура и использование современных технологий позволяют легко расширять функциональность системы, добавляя новые возможности: автоматический парсинг новостей, систему уведомлений, полнотекстовый поиск, аналитику и статистику.

**Перспективы развития:**

1. Реализация автоматического парсинга новостей из RSS-лент источников
2. Добавление системы уведомлений в реальном времени с использованием WebSocket
3. Внедрение полнотекстового поиска по статьям с использованием Elasticsearch
4. Разработка системы рекомендаций статей на основе предпочтений пользователя
5. Добавление функционала комментариев к статьям с модерацией
6. Реализация механизмов кеширования (Redis) для повышения производительности
7. Интеграция системы аналитики для отслеживания популярности статей и активности пользователей
8. Разработка мобильного приложения для iOS и Android

В результате выполнения курсового проекта получены практические навыки разработки современных веб-приложений с использованием актуального технологического стека, освоены принципы проектирования архитектуры, работы с базами данных, обеспечения безопасности и тестирования программного обеспечения.
