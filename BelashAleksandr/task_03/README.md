## Правила нумерации

- **Разделы:** используют префиксы 01_, 02_, ..., 09_
- **Подразделы:** нумеруются внутри раздела (01_, 02_, ...)
- **Рисунки:** используют формат N.M (например, 2.1, 3.2, 4.1), где N — номер раздела, M — порядковый номер рисунка в разделе
- **Таблицы:** используют аналогичный формат N.M
- **Ссылки на источники:** сквозная нумерация [1], [2], ..., [40]
