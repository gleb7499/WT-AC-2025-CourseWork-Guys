# Введение

В современном мире информационные технологии играют ключевую роль в распространении новостного контента. Ежедневно миллионы пользователей обращаются к различным источникам информации, однако растущая проблема недостоверных данных и фейковых новостей создаёт необходимость в инструментах для верификации и модерации контента [3]. Актуальность разработки систем, обеспечивающих доступ к проверенным источникам информации с механизмами общественного контроля, продолжает возрастать.

Проект «Агрегатор новостей "Без фейков"» представляет собой веб-платформу, направленную на решение проблемы доверия к новостному контенту через прозрачную систему модерации и работу с проверенными источниками. Вариант проекта (номер 37) предусматривает реализацию MVP-функциональности с базовыми сущностями: источники новостей, статьи, теги, избранное, жалобы и пользователи. Система обеспечивает разграничение прав доступа между тремя ролями пользователей и предоставляет API-интерфейсы для управления основными ресурсами.

Целью данной курсовой работы является проектирование и разработка полнофункционального веб-приложения агрегатора новостей с системой модерации контента, реализующего клиент-серверную архитектуру и современные подходы к обеспечению информационной безопасности.

Для достижения поставленной цели были сформулированы следующие задачи:

Провести анализ предметной области и сформулировать функциональные и нефункциональные требования к системе на основе технического задания варианта 37. Определить состав основных сущностей данных, их атрибуты и связи между ними.

Спроектировать архитектуру приложения с учётом разделения на клиентскую и серверную части, разработать модель данных и API-спецификацию для обеспечения взаимодействия компонентов системы. Определить алгоритмы ключевых операций, включая формирование ленты новостей, обработку фильтров, управление избранным и процесс модерации жалоб.

Реализовать серверную часть приложения на платформе Node.js с использованием фреймворка Express, системы управления базами данных PostgreSQL и ORM Prisma для взаимодействия с данными. Обеспечить валидацию входных данных, обработку ошибок и логирование операций.

Разработать клиентскую часть на базе библиотеки React с применением TypeScript для типобезопасности, реализовать пользовательский интерфейс для всех предусмотренных сценариев использования с учётом ролевой модели доступа.

Интегрировать механизмы аутентификации и авторизации на основе JWT-токенов, реализовать ролевую модель с тремя уровнями доступа: обычный пользователь, модератор и администратор. Обеспечить защиту конфиденциальных данных через хеширование паролей и настройку безопасных HTTP-заголовков [4].

Подготовить инструкции по развёртыванию и запуску приложения, включая настройку окружения, инициализацию базы данных и заполнение тестовыми данными для демонстрации функциональности.

Описание варианта 37 предусматривает создание системы с приоритетом на качество и достоверность новостного контента. Ключевыми особенностями проекта являются модульная архитектура с чёткими API-границами, гибкая система тегирования для категоризации материалов, персонализированное избранное для сохранения интересных статей и эффективная система модерации жалоб, позволяющая уполномоченным пользователям оперативно реагировать на сомнительный контент.
