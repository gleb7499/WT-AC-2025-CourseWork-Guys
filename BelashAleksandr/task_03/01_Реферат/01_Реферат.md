# Реферат

Данная курсовая работа посвящена разработке веб-приложения «Агрегатор новостей "Без фейков"» — информационной системы для сбора, структурирования и модерации новостного контента. Система предоставляет пользователям доступ к проверенным новостным источникам с возможностью фильтрации по тегам, добавления материалов в избранное и подачи жалоб на сомнительный контент.

В работе представлены результаты полного цикла разработки программного продукта: анализ требований, проектирование архитектуры и модели данных, реализация клиент-серверного приложения с использованием современного технологического стека, а также интеграция механизмов безопасности и модерации. Система реализована на базе технологий Node.js, Express, PostgreSQL на серверной стороне и React с TypeScript на клиентской части.

Основное внимание уделено разработке гибкой ролевой модели с тремя уровнями доступа, реализации RESTful API для взаимодействия компонентов системы, созданию алгоритмов модерации пользовательских жалоб и обеспечению безопасности данных через механизмы аутентификации на основе JWT-токенов [1]. Архитектура приложения построена с учётом принципов разделения ответственности и масштабируемости [2].

Функциональность системы охватывает работу с источниками новостей, агрегацию и отображение статей в ленте, управление тегами для категоризации контента, персонализированное избранное для каждого пользователя и полноценную систему модерации жалоб с возможностью рассмотрения и принятия решений уполномоченными пользователями.

В результате выполнения работы создан функционирующий прототип веб-приложения, соответствующий заявленным требованиям MVP, с детальной документацией архитектуры, API-спецификацией и инструкциями по развёртыванию.

**Ключевые слова:** агрегатор новостей, веб-приложение, модерация контента, RESTful API, Node.js, Express, PostgreSQL, React, TypeScript, JWT-аутентификация, ролевая модель доступа, Prisma ORM
