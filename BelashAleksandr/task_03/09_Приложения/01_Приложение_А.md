# **ПРОГРАММНЫЙ КОД АЛГОРИТМОВ СИСТЕМЫ**

Полный исходный код проекта «Новости "Без фейков"» доступен в публичном репозитории GitHub:

**URL репозитория:**
https://github.com/brstu/WT-AC-2025-CourseWorks/tree/main/BelashAleksandr

**Структура репозитория:**

- **task_01/** — документация требований (R1)
  - R1_Routes.md — маршруты и пользовательские сценарии
  - R1_Roles_and_Actions.md — роли и действия пользователей
  - R1_Matrix_of_Rights.md — матрица прав доступа
  - R1_DataModel_and_API.md — модель данных и спецификация API
  - R1_ERD.md — диаграмма сущностей (ERD)
  - R1_WBS.md — структура декомпозиции работ
  - R1_Cards.md — карточки требований с критериями валидации

- **task_02/** — исходный код проекта
  - apps/server/ — серверная часть (Node.js + Express + Prisma)
    - src/ — исходные файлы TypeScript
    - prisma/ — схема базы данных и миграции
  - apps/web/ — клиентская часть (React + TypeScript + Vite)
    - src/ — исходные файлы React-компонентов
  - docker-compose.yml — конфигурация Docker Compose
  - README.md — инструкция по запуску и использованию

- **task_03/** — пояснительная записка курсового проекта (текущий документ)

**Инструкция по доступу к коду:**

1. Перейти по указанной выше ссылке на GitHub
2. Ознакомиться с файлом README.md в папке task_02/ для получения инструкций по запуску
3. Клонировать репозиторий для локального запуска:
   ```bash
   git clone https://github.com/brstu/WT-AC-2025-CourseWorks.git
   cd WT-AC-2025-CourseWorks/BelashAleksandr/task_02
   ```
4. Следовать инструкциям из README.md для установки зависимостей и запуска приложения

**Ключевые файлы исходного кода:**

- **Серверная часть:**
  - `apps/server/src/index.ts` — точка входа приложения
  - `apps/server/prisma/schema.prisma` — схема базы данных
  - `apps/server/src/routes/` — определения маршрутов API
  - `apps/server/src/controllers/` — контроллеры обработки запросов
  - `apps/server/src/services/` — бизнес-логика приложения
  - `apps/server/src/middleware/` — middleware для аутентификации и валидации

- **Клиентская часть:**
  - `apps/web/src/App.tsx` — корневой компонент приложения
  - `apps/web/src/pages/` — страницы приложения
  - `apps/web/src/components/` — переиспользуемые компоненты
  - `apps/web/src/store/` — управление состоянием (Zustand)
  - `apps/web/src/api/` — функции взаимодействия с API
