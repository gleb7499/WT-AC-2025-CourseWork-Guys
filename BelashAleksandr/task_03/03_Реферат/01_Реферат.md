# **Реферат**

Курсовой проект посвящен разработке веб-приложения для агрегации новостей «Без фейков» с системой модерации жалоб. Система реализует функционал сбора и отображения новостей из различных источников с возможностью фильтрации, работы с избранным и подачи жалоб на недостоверный контент. Проект включает разработку клиентской и серверной частей с использованием современных веб-технологий. Реализована ролевая модель доступа с тремя типами пользователей: администратор, модератор и обычный пользователь. Система обеспечивает хранение данных в реляционной базе данных PostgreSQL, аутентификацию пользователей на основе JWT-токенов и валидацию входных данных.

Пояснительная записка содержит 9 разделов, включает описание постановки задачи, разработку алгоритмов и программной реализации, описание процесса тестирования и результатов работы системы.

**Ключевые слова:** веб-приложение, агрегация новостей, модерация контента, React, Node.js, Express, PostgreSQL, TypeScript, REST API, JWT аутентификация, ролевая модель доступа, Prisma ORM
