Для рисунка 4.1 – Главная страница с лентой новостей:

Открыть приложение в браузере по адресу http://localhost:5173
Войти в систему как обычный пользователь (username: user, password: user123)

Сделать скриншот главной страницы, на котором должны быть видны:
- Навигационное меню в header (Лента, Избранное, имя пользователя, кнопка выхода)
- Заголовок страницы "Лента новостей"
- Панель фильтров с выпадающими списками (Фильтр по тегам, Фильтр по источникам)
- Список карточек статей (минимум 3-4 статьи)
- На каждой карточке: заголовок статьи, краткое описание, источник, теги, дата публикации
- Кнопки/иконки для добавления в избранное и подачи жалобы

Скриншот должен быть на полную высоту экрана или показывать основную часть интерфейса.
