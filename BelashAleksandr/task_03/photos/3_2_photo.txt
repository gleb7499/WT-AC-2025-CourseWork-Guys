Для рисунка 3.2 – Главная страница ленты новостей:

Запустить приложение согласно инструкциям в task_02/README.md:
1. Установить зависимости: pnpm install
2. Настроить PostgreSQL и переменные окружения
3. Выполнить миграции: pnpm db:push и pnpm db:seed
4. Запустить приложение: pnpm dev

Войти в систему под учётной записью обычного пользователя:
- Логин: user
- Пароль: user123

Сделать скриншот главной страницы с лентой новостей (обычно доступна по адресу http://localhost:5173).

На скриншоте должны быть видны:
- Навигационное меню с разделами приложения
- Список статей в ленте с заголовками, источниками, датами публикации
- Фильтры по тегам и/или источникам (если реализованы в UI)
- Кнопки для взаимодействия (добавить в избранное, подробнее и т.д.)
- Пагинация или скролл для навигации по статьям

Сохранить скриншот как 3_2_photo.png или 3_2_photo.jpg и заменить этот файл.
