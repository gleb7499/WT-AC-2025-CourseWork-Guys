Для рисунка 3.1 – Архитектура системы:
Создать архитектурную диаграму системы, показывающую три основных компонента:
1. Браузер с React-приложением (клиентская часть)
2. Node.js сервер с Express (серверная часть)
3. База данных PostgreSQL (уровень хранения данных)

На диаграмме должны быть показаны связи между компонентами:
- HTTP/JSON запросы между браузером и сервером
- Prisma ORM для взаимодействия между сервером и БД
- Стрелки, указывающие направление потока данных

Диаграму можно нарисовать в любом редакторе диаграмм (draw.io, Lucidchart, Miro) или использовать специализированные инструменты для архитектурных диаграмм.
