Для рисунка 3.1 – Компонентная архитектура системы:

Создать диаграмму архитектуры системы, показывающую взаимодействие основных компонентов:

Уровень 1 (Клиент):
- Браузер пользователя
- React Application (Single Page Application)
  - React Router (маршрутизация)
  - Zustand (управление состоянием)
  - Axios (HTTP-клиент)

Уровень 2 (Сервер):
- Node.js + Express Server
  - API Routes (/auth, /users, /sources, /feed, /tags, /favorites, /reports)
  - Middleware (authentication, authorization, validation, error handling)
  - Controllers (бизнес-логика)
  - Prisma ORM

Уровень 3 (База данных):
- PostgreSQL Database
  - Таблицы: users, sources, articles, tags, article_tags, favorites, reports

Взаимодействия:
- Браузер <--HTTP/REST API--> Express Server (стрелки в обе стороны)
- Express Server <--SQL запросы через Prisma--> PostgreSQL (стрелки в обе стороны)

Дополнительно показать:
- JWT токены в заголовках Authorization для защищённых запросов
- CORS и Helmet для безопасности
- JSON формат обмена данными между клиентом и сервером
