Для рисунка 3.1 – Архитектура системы:

Создать схему архитектуры системы, показывающую взаимодействие между компонентами:

1. **Браузер пользователя** (User Browser) - React SPA
2. **API Server** (Node.js + Express) со следующими слоями:
   - Routes (маршрутизация)
   - Controllers (обработка запросов)
   - Services (бизнес-логика)
   - Middleware (аутентификация, валидация)
3. **Prisma ORM** (слой доступа к данным)
4. **PostgreSQL Database** (база данных)

Стрелки должны показывать направление взаимодействия:
- HTTP запросы от браузера к API Server
- Обработка запросов через слои Routes → Controllers → Services
- Запросы от Services к базе данных через Prisma ORM
- Ответы в обратном направлении

Дополнительно показать:
- Docker контейнеры для каждого компонента
- Порты (Frontend: 5173, Backend: 3000, PostgreSQL: 5432)

Использовать инструмент для создания архитектурных диаграмм (draw.io, lucidchart, или C4 model).
