Для рисунка 2.2 – Схема аутентификации с использованием JWT:

Создать диаграмму последовательности (sequence diagram), показывающую процесс аутентификации пользователя:

1. Клиент отправляет запрос POST /api/auth/login с username и password
2. Сервер проверяет учётные данные в базе данных
3. Сервер генерирует Access Token (JWT, срок жизни 15 минут)
4. Сервер генерирует Refresh Token (JWT, срок жизни 7 дней)
5. Сервер устанавливает Refresh Token в HttpOnly cookie
6. Сервер возвращает Access Token и информацию о пользователе клиенту
7. Клиент сохраняет Access Token для последующих запросов
8. При запросах к защищённым endpoints клиент передаёт Access Token в заголовке Authorization: Bearer <token>

На диаграмме должны быть показаны участники: Client (Frontend), API Server, Database.
Можно использовать инструмент для создания диаграмм (draw.io, lucidchart) или текстовую Mermaid-диаграмму.
