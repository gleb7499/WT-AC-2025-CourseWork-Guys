Для рисунка 3.3 – Структура клиентской части:

Создать дерево файлов и папок клиентской части проекта (apps/web):

```
apps/web/
├── src/
│   ├── main.tsx
│   ├── App.tsx
│   ├── pages/
│   │   ├── LoginPage.tsx
│   │   ├── RegisterPage.tsx
│   │   ├── FeedPage.tsx
│   │   ├── ArticlePage.tsx
│   │   ├── FavoritesPage.tsx
│   │   ├── SourcesPage.tsx
│   │   ├── TagsPage.tsx
│   │   ├── ReportsPage.tsx
│   │   ├── UsersPage.tsx
│   │   └── NotFoundPage.tsx
│   ├── components/
│   │   ├── Layout.tsx
│   │   ├── Header.tsx
│   │   ├── ArticleCard.tsx
│   │   ├── ArticleList.tsx
│   │   ├── FilterPanel.tsx
│   │   ├── FavoriteButton.tsx
│   │   ├── ReportButton.tsx
│   │   ├── PrivateRoute.tsx
│   │   └── ...
│   ├── store/
│   │   ├── authStore.ts
│   │   ├── feedStore.ts
│   │   ├── sourcesStore.ts
│   │   ├── tagsStore.ts
│   │   ├── favoritesStore.ts
│   │   └── reportsStore.ts
│   ├── api/
│   │   ├── axiosInstance.ts
│   │   ├── authApi.ts
│   │   ├── usersApi.ts
│   │   ├── sourcesApi.ts
│   │   ├── feedApi.ts
│   │   └── ...
│   ├── types/
│   │   ├── user.types.ts
│   │   ├── article.types.ts
│   │   └── ...
│   ├── utils/
│   │   ├── dateFormatter.ts
│   │   └── validators.ts
│   └── styles/
│       └── index.css
├── package.json
├── vite.config.ts
└── index.html
```

Можно сделать скриншот файловой структуры из VS Code или создать визуальную схему в виде дерева папок.
