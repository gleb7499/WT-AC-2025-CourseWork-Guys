Для рисунка 5.1 – Архитектура системы:

Создать диаграмму, показывающую трёхуровневую архитектуру системы:
1. Верхний уровень: Клиентский браузер с React приложением
2. Средний уровень: Next.js сервер с API routes
3. Нижний уровень: MongoDB база данных

Диаграмма должна показывать:
- Стрелки HTTP/REST между клиентом и сервером
- Стрелки между сервером и БД
- Основные компоненты каждого уровня
- JWT токен в заголовках запросов

Можно создать блок-схему в любом графическом редакторе или использовать инструменты для создания диаграмм (draw.io, Lucidchart и т.п.).
