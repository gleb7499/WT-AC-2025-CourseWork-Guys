# Реферат

Работа посвящена проектированию и разработке веб-приложения для совместного ведения заметок «Пишем вдвоём». Система реализует функциональность по созданию тетрадей, управлению заметками, организации контента с помощью меток и предоставлению различных уровней доступа для совместной работы пользователей.

В рамках курсового проекта выполнены следующие этапы: сформулирована постановка задачи на основе функциональных и нефункциональных требований, спроектирована модель данных с определением сущностей и связей между ними, разработаны алгоритмы для ключевых операций системы, реализовано полнофункциональное веб-приложение на базе современного технологического стека [1].

Архитектура системы построена по принципу клиент-сервер с чётким разделением ответственности. Серверная часть реализована на Node.js с использованием Express и обеспечивает REST API для взаимодействия с клиентскими приложениями. Для хранения данных применяется реляционная СУБД PostgreSQL, доступ к которой организован через ORM Prisma. Клиентская часть представляет собой одностраничное приложение на React, обеспечивающее интерактивный пользовательский интерфейс [2].

Особое внимание уделено механизму разграничения прав доступа и совместной работы нескольких пользователей над общими тетрадями. Реализована система аутентификации на основе JWT с использованием пары токенов для повышения безопасности. Предусмотрены два уровня полномочий пользователей и возможность гибкого управления доступом к отдельным тетрадям [3].

Результатом работы является полностью функциональное веб-приложение, отвечающее требованиям MVP и готовое к развёртыванию в производственной среде. Система прошла проверку на соответствие критериям приёмки, включая корректную работу механизма совместного доступа к данным.

**Ключевые слова**: веб-приложение, REST API, совместное редактирование, управление доступом, Node.js, React, PostgreSQL, JWT, заметки, тетради.
