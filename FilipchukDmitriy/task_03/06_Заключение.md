# Заключение

В рамках курсового проекта выполнена разработка полнофункционального веб-приложения для совместного ведения заметок «Пишем вдвоём», отвечающего требованиям MVP и готового к развёртыванию в производственной среде.

Проведён анализ предметной области и сформулированы функциональные и нефункциональные требования к системе. Определены основные сущности данных и связи между ними, разработана модель данных с учётом требований целостности и эффективности доступа. Спроектирована трёхзвенная архитектура системы с чётким разделением ответственности между клиентским уровнем представления, серверным уровнем бизнес-логики и уровнем данных [1].

Разработаны алгоритмы для ключевых операций системы, включая формирование списка доступных тетрадей с учётом прав владения и совместного доступа, проверку прав доступа к операциям на основе ролевой модели и механизма share, аутентификацию с использованием пары JWT токенов, сохранение истории изменений заметок и фильтрацию заметок по меткам [2].

Реализовано серверное приложение на базе Node.js и Express, предоставляющее REST API для всех операций с данными. Применён ORM Prisma для типобезопасного взаимодействия с базой данных PostgreSQL. Обеспечена безопасность системы путём хэширования паролей с использованием bcrypt, реализации аутентификации на основе JWT, установки защитных HTTP заголовков и валидации всех входных данных [3].

Разработано клиентское одностраничное приложение на React с интуитивно понятным пользовательским интерфейсом. Реализованы страницы для управления тетрадями, заметками, метками и предоставлением доступа. Организовано взаимодействие с серверным API с автоматической обработкой ошибок и обновлением токенов аутентификации [4].

Особое внимание уделено реализации механизма совместного доступа к тетрадям, являющегося ключевой функциональностью системы. Владелец тетради может предоставить другому пользователю доступ на чтение или редактирование. Пользователи с доступом видят расшаренные тетради в своём списке и могут выполнять операции в соответствии с уровнем предоставленных прав. Владелец может в любой момент отозвать ранее предоставленный доступ [5].

Система прошла проверку на соответствие всем критериям приёмки MVP. Подтверждена корректная работа регистрации и аутентификации пользователей, создания и управления тетрадями и заметками, работы с метками, предоставления и отзыва доступа к тетрадям, использования расшаренных тетрадей с учётом уровня прав, просмотра истории изменений заметок, разграничения прав администратора и обработки ошибочных ситуаций [6].

Подготовлена документация по конфигурации окружения и инструкции по запуску приложения в режимах разработки и продакшена. Структура проекта организована с учётом возможности дальнейшего развития и масштабирования [7].

Разработанная система демонстрирует применение современных подходов и технологий веб-разработки. Архитектурные решения обеспечивают модульность, тестируемость и масштабируемость кода. Выбранный технологический стек предоставляет баланс между производительностью, безопасностью и скоростью разработки [8].

Направления дальнейшего развития системы могут включать реализацию совместного редактирования заметок в реальном времени с использованием WebSocket, добавление полнотекстового поиска по содержимому заметок, реализацию возможности экспорта заметок во внешние форматы, добавление поддержки вложенных файлов и медиа-контента, реализацию офлайн-режима с синхронизацией изменений, расширение функциональности меток с поддержкой иерархии и автоматической категоризации [9].

Результаты работы подтверждают достижение поставленной цели и решение всех определённых задач. Созданное веб-приложение представляет собой функциональный инструмент для организации личных и совместных заметок, готовый к использованию реальными пользователями [10].
