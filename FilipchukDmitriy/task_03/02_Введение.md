# Введение

Современный ритм работы и учёбы требует эффективных инструментов для организации личной и коллективной информации. Заметки являются одним из базовых средств фиксации идей, планирования задач и структурирования знаний. При этом возрастает потребность в совместной работе над документами, когда несколько пользователей могут одновременно редактировать и дополнять общий контент [1].

Актуальность данной работы обусловлена необходимостью создания удобного и безопасного решения для ведения заметок с возможностью совместного доступа. Существующие решения либо предоставляют ограниченный функционал бесплатно, либо требуют изучения сложных интерфейсов. Разработка системы, позволяющей пользователям эффективно организовывать заметки в структуру тетрадей, применять метки для категоризации и гибко управлять правами доступа, представляет практический интерес как для индивидуального использования, так и для небольших рабочих групп [2].

Настоящий курсовой проект выполнен на основе варианта 16 «Заметки «Пишем вдвоём»». Основная концепция варианта заключается в реализации MVP-функциональности, включающей работу с тетрадями, заметками, метками и совместным доступом. Ключевой особенностью является возможность предоставления другим пользователям прав на чтение или редактирование отдельных тетрадей, что обеспечивает гибкую модель коллаборации [3].

**Цель работы** — спроектировать и реализовать полнофункциональное веб-приложение для совместного ведения заметок с разграничением прав доступа.

Для достижения поставленной цели необходимо решить следующие **задачи**:

1. Провести анализ предметной области и сформулировать функциональные и нефункциональные требования к системе.
2. Разработать модель данных, описывающую структуру сущностей и связи между ними.
3. Спроектировать архитектуру системы с определением основных компонентов и их взаимодействия.
4. Реализовать серверную часть приложения с REST API для управления данными.
5. Разработать клиентское приложение с интерактивным пользовательским интерфейсом.
6. Реализовать механизм аутентификации и авторизации с учётом ролевой модели.
7. Обеспечить корректную работу системы совместного доступа к тетрадям.
8. Провести тестирование функциональности системы на соответствие критериям приёмки.

Разработанная система должна обеспечивать удобство использования, надёжность хранения данных и безопасность при работе с конфиденциальной информацией пользователей.
