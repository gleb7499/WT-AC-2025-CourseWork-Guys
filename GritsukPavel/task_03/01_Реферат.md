# Реферат

Настоящая работа посвящена разработке веб-приложения для управления откликами на вакансии «Оффер где?». Система реализована в виде полнофункционального веб-приложения на стеке технологий React, Express и PostgreSQL [1]. Приложение предоставляет пользователям возможность отслеживать процесс поиска работы через визуализацию вакансий в формате канбан-доски, управлять информацией о компаниях, создавать заметки и настраивать напоминания о важных событиях [2].

В работе представлена архитектура системы, состоящей из клиентской части на основе React с использованием библиотеки React Router для навигации, серверной части на Express с использованием Prisma ORM для работы с базой данных PostgreSQL [3]. Реализованы механизмы аутентификации и авторизации на основе JWT-токенов с поддержкой refresh-механизма для безопасного управления сессиями [4]. Система обеспечивает разграничение прав доступа между ролями администратора и обычного пользователя.

Функциональность приложения включает управление компаниями, вакансиями, этапами отклика, заметками и напоминаниями. Канбан-доска позволяет визуально отслеживать статус каждой вакансии и перемещать их между этапами. Реализована валидация данных на стороне клиента и сервера, обработка ошибок и защита от распространённых угроз безопасности [5].

В пояснительной записке представлены постановка задачи, описание разработанных алгоритмов обработки данных и взаимодействия компонентов системы, детальное описание реализации программы с указанием используемых технологий и архитектурных решений. Приведены инструкции по развёртыванию и запуску приложения.

**Ключевые слова:** веб-приложение, поиск работы, канбан, React, Express, PostgreSQL, REST API, JWT, аутентификация, система управления откликами.
