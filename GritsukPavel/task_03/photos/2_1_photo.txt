Для рисунка 2.1 – Диаграмма связей сущностей системы:

Создать диаграмму ERD (Entity-Relationship Diagram), показывающую связи между сущностями User, Company, Job, Stage, Note и Reminder. На диаграмме должны быть отображены:
- Прямоугольники для каждой сущности с указанием названия
- Линии связей между сущностями со стрелками
- Указание кардинальности связей (1:N, 1:1)
- Ключевые поля каждой сущности (id, внешние ключи)

Связи для отображения:
- User → Company (1:N)
- User → Job (1:N)
- Company → Job (1:N)
- Job → Stage (1:N)
- Job → Note (1:N)
- Job → Reminder (1:N)
- Job → Stage (currentStageId, 1:1)

Диаграмму можно создать с помощью инструментов dbdiagram.io, draw.io или аналогичных, либо использовать Mermaid ERD из файла task_01/R1_ERD.md как основу.
