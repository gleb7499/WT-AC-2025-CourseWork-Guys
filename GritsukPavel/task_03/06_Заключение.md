# Заключение

В рамках данной работы была разработана полнофункциональная система управления откликами на вакансии «Оффер где?», реализованная в виде веб-приложения на современном технологическом стеке [1]. Система обеспечивает пользователям возможность эффективно отслеживать процесс поиска работы через визуализацию вакансий в формате канбан-доски с управлением сопутствующей информацией.

Поставленная цель разработки специализированного инструмента для управления откликами на вакансии была достигнута в полном объёме. Реализованная система предоставляет пользователям интуитивно понятный интерфейс для систематизации информации о компаниях, вакансиях, этапах отбора, заметках и напоминаниях [1]. Канбан-доска обеспечивает наглядное отображение статуса каждого отклика и упрощает управление процессом поиска работы [1].

В процессе выполнения работы были решены все поставленные задачи. Проведён анализ требований к функциональности системы и определены ключевые сущности предметной области, включающие пользователей, компании, вакансии, этапы, заметки и напоминания [2]. Спроектирована реляционная модель данных с использованием шести основных таблиц и установлением связей через внешние ключи с поддержкой каскадного удаления [2].

Разработаны алгоритмы обработки данных, включающие формирование структуры канбан-доски с группировкой вакансий по этапам, обработку перемещений вакансий между этапами с обновлением состояния, управление напоминаниями с валидацией дат и реализацию механизмов аутентификации и авторизации [5]. Алгоритмы обеспечивают корректную обработку данных с соблюдением правил безопасности и целостности [2].

Реализована серверная часть приложения на платформе Node.js с фреймворком Express, предоставляющая REST API для выполнения всех необходимых операций [1]. API включает endpoints для регистрации и аутентификации пользователей, управления компаниями, вакансиями, этапами, заметками и напоминаниями, а также специализированный endpoint для получения данных канбан-доски [2]. Все endpoints защищены механизмами аутентификации и авторизации [5].

Реализована клиентская часть приложения с использованием библиотеки React, обеспечивающая интерактивный пользовательский интерфейс [3]. Интерфейс включает страницы регистрации и входа, главную страницу с канбан-доской, страницы управления компаниями и вакансиями, детальные страницы вакансий с отображением связанных этапов, заметок и напоминаний [1]. Реализована возможность перетаскивания карточек вакансий между этапами на канбане [1].

Обеспечена безопасность системы путём реализации аутентификации на основе JWT-токенов с разделением на короткоживущие access-токены и долгоживущие refresh-токены [5]. Пароли пользователей хешируются с использованием алгоритма bcrypt [5]. Refresh-токены хранятся в защищённых HTTP-only cookies для предотвращения XSS-атак [5]. Реализовано разграничение прав доступа между ролями администратора и обычного пользователя [2]. Пользователи имеют доступ только к собственным данным [2].

Подготовлены инструкции по развёртыванию и использованию приложения, включающие настройку окружения, применение миграций базы данных и запуск серверной и клиентской частей [1]. Проект организован в виде монорепозитория с использованием npm workspaces для упрощения управления зависимостями [3].

Разработанная система соответствует всем критериям приёмки минимально работоспособного продукта [1]. База данных содержит все необходимые таблицы с корректно настроенными связями [2]. API предоставляет endpoints для всех требуемых операций с валидацией входных данных и единообразным форматом ответов [2]. Аутентификация работает на основе JWT-токенов с refresh-механизмом [5]. Авторизация обеспечивает изоляцию данных между пользователями [2]. Клиентское приложение предоставляет полнофункциональный интерфейс для работы со всеми сущностями системы [3]. Канбан-доска корректно отображает вакансии с возможностью перемещения между этапами [1].

Выбранный технологический стек показал свою эффективность для решения поставленных задач [1]. Использование React обеспечило создание отзывчивого и интуитивного пользовательского интерфейса [3]. Express предоставил гибкий инструментарий для построения REST API [1]. PostgreSQL обеспечила надёжное хранение данных с поддержкой сложных запросов [1]. Prisma ORM упростила взаимодействие с базой данных и обеспечила типобезопасность [1].

Практическая значимость работы заключается в создании готового к использованию инструмента, который может применяться соискателями для эффективного управления процессом поиска работы. Система позволяет систематизировать информацию о множестве откликов, визуально отслеживать прогресс по каждой вакансии, фиксировать важные детали в заметках и не пропускать важные события благодаря напоминаниям.

**Направления дальнейшего развития** проекта включают реализацию уведомлений о напоминаниях в реальном времени через WebSocket-соединения [2], добавление возможности прикрепления файлов к вакансиям и заметкам для хранения резюме и сопроводительных писем [3], экспорт данных в форматы Excel и PDF для внешнего анализа [3], интеграцию с внешними API сервисов поиска работы для автоматического импорта вакансий [3], реализацию мобильного приложения для доступа к системе с мобильных устройств [3], добавление аналитики и визуализации статистики откликов с построением графиков динамики [1], расширение функциональности напоминаний с отправкой email или push-уведомлений [3].

Также перспективным направлением является добавление возможности совместного использования данных между пользователями для командного поиска работы или консультирования [2], реализация системы тегов для категоризации вакансий по направлениям [3], интеграция с календарями для синхронизации дат собеседований [3], добавление шаблонов для заметок и напоминаний [3], реализация резервного копирования и восстановления данных пользователя [4].

Таким образом, в результате выполнения работы создана полнофункциональная система управления откликами на вакансии, соответствующая всем требованиям задания и готовая к практическому использованию. Разработанная архитектура и технологический стек обеспечивают возможность дальнейшего развития и масштабирования системы.
