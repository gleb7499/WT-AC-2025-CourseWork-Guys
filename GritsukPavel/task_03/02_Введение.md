# Введение

Современный рынок труда характеризуется высокой конкуренцией и динамичностью процессов подбора персонала. Соискателям приходится одновременно отслеживать множество откликов на вакансии в различных компаниях, фиксировать результаты собеседований, устанавливать напоминания о предстоящих встречах и систематизировать накопленную информацию [1]. Отсутствие единого инструмента для управления этими процессами приводит к потере важных данных, пропуску дедлайнов и снижению эффективности поиска работы.

Существующие решения, такие как электронные таблицы или универсальные системы управления задачами, не учитывают специфику процесса поиска работы и не предоставляют удобной визуализации статуса откликов [2]. Это определяет актуальность разработки специализированного инструмента, ориентированного на потребности соискателей.

**Цель работы** — разработать веб-приложение для управления откликами на вакансии с визуализацией процесса в формате канбан-доски, обеспечивающее систематизацию информации о компаниях, вакансиях, этапах отбора, заметках и напоминаниях.

Для достижения поставленной цели необходимо решить следующие **задачи**:

1. Проанализировать требования к функциональности системы и определить ключевые сущности предметной области.
2. Спроектировать модель данных, обеспечивающую хранение информации о пользователях, компаниях, вакансиях, этапах, заметках и напоминаниях.
3. Разработать алгоритмы обработки данных, включая формирование канбан-доски, управление этапами вакансий и обработку напоминаний.
4. Реализовать серверную часть приложения с REST API для выполнения операций создания, чтения, обновления и удаления данных.
5. Реализовать клиентскую часть приложения с пользовательским интерфейсом для работы с канбан-доской и управления данными.
6. Обеспечить безопасность системы путём реализации аутентификации, авторизации и защиты от распространённых угроз.
7. Подготовить инструкции по развёртыванию и использованию приложения.

Разрабатываемая система соответствует варианту 32 — «Поиск работы «Оффер где?»» [3]. Основная идея проекта заключается в предоставлении соискателям инструмента для профессионального отслеживания откликов на вакансии. Минимально работоспособный продукт включает управление сущностями Job, Stage, Note, Reminder, Company и User [3]. Система предоставляет API-endpoints для работы с данными и пользовательский интерфейс в виде канбан-доски для визуального отображения статусов вакансий.

Работа структурирована следующим образом. В разделе «Постановка задачи» приведены функциональные и нефункциональные требования к системе, описаны ограничения и критерии приёмки. Раздел «Разработка алгоритмов» содержит описание сущностей и связей, алгоритмы ключевых операций и схему аутентификации. В разделе «Разработка программы» представлена архитектура системы, обоснование выбора технологического стека, описание модулей сервера и клиента, спецификация API и модель данных. Заключение содержит выводы по результатам работы и направления дальнейшего развития проекта.
