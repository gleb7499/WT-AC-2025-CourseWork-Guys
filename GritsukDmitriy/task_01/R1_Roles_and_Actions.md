# Вариант 24 — Roadmaps «Как стать джуном» — Роли и действия

Краткое описание

MVP: Roadmap, Step, Resource, Progress, User. UI отображает дорожные карты с шагами и трекинг прогресса; API: /roadmaps, /steps, /progress, /resources. Приёмка (MVP): корректный трекинг прогресса пользователя по шагам дорожной карты.

Роли и основные действия

- Администратор
  - CRUD для пользователей
  - CRUD для дорожных карт (Roadmap)
  - CRUD для шагов (Step)
  - CRUD для ресурсов (Resource)
  - Просмотр прогресса всех пользователей

- Пользователь
  - Просмотр списка дорожных карт
  - Просмотр шагов и ресурсов
  - Отметка шагов как выполненных (Progress)
  - Просмотр своего прогресса

Примеры сценариев

- Администратор создаёт Roadmap «Frontend Developer», добавляет шаги (HTML, CSS, JS...), прикрепляет ресурсы → пользователь видит карту и начинает проходить.
- Пользователь открывает Roadmap, изучает шаг, отмечает его как выполненный → система обновляет Progress и показывает процент завершения.
