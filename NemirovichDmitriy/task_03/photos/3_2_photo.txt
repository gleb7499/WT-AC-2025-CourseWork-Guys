Для рисунка 3.2 – Список поездок пользователя:

Запустить приложение «Поехали!» в браузере и сделать скриншот главной страницы со списком поездок.

Инструкция:
1. Запустить backend и frontend согласно README (npm run dev)
2. Открыть http://localhost:5173 в браузере
3. Войти в систему как пользователь user1@example.com / User1234 (после выполнения seed)
4. После входа откроется страница со списком поездок
5. Сделать скриншот страницы

На скриншоте должны быть видны:
- Навигационное меню/заголовок с названием приложения «Поехали!»
- Кнопка «Создать поездку» или аналогичная
- Список карточек поездок с информацией:
  * Название поездки
  * Даты (начало-окончание)
  * Бюджет (если указан)
  * Количество участников
  * Кнопки действий: «Просмотр», «Редактировать», «Удалить» (в зависимости от прав)
- Информация о владельце/участии пользователя в поездке

Если поездок пока нет, можно создать одну-две тестовых поездки перед скриншотом, чтобы продемонстрировать интерфейс списка.
