Для рисунка 3.1 – Архитектура системы:

Создать диаграмму, иллюстрирующую трёхуровневую архитектуру системы «Поехали!».

Диаграмма должна содержать три основных блока, расположенных вертикально или слева направо:

1. **Уровень представления (Клиент)**:
   - Обозначить как «React SPA»
   - Указать: «Браузер пользователя»
   - Компоненты: UI компоненты, формы, роутинг

2. **Прикладной уровень (Сервер)**:
   - Обозначить как «Node.js + Express»
   - Указать основные модули: Auth, Trips, Stops, Notes, Expenses
   - Middleware: аутентификация, авторизация
   - REST API endpoints

3. **Уровень данных**:
   - Обозначить как «PostgreSQL»
   - Указать: ORM Prisma
   - Таблицы: users, trips, stops, notes, expenses, trip_participants

Между блоками показать стрелки взаимодействия:
- От клиента к серверу: «HTTP/HTTPS REST API (JSON)»
- От сервера к БД: «SQL запросы через Prisma ORM»

Можно использовать инструменты: draw.io, Lucidchart, PlantUML или аналогичные редакторы диаграмм.
