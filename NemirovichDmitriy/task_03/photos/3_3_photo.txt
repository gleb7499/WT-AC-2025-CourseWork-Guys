Для рисунка 3.3 – Форма создания остановки:

Запустить приложение и сделать скриншот формы добавления новой остановки к поездке.

Инструкция:
1. Запустить приложение (npm run dev)
2. Войти в систему как пользователь
3. Перейти к детальной странице любой существующей поездки (или создать новую)
4. Перейти на вкладку «Остановки» или «Маршрут»
5. Нажать кнопку «Добавить остановку» или «Создать остановку»
6. Откроется модальное окно или форма с полями для ввода данных
7. Сделать скриншот этой формы

На скриншоте должны быть видны поля формы:
- Название остановки (обязательное поле)
- Адрес (опциональное поле)
- Широта (latitude) — числовое поле
- Долгота (longitude) — числовое поле
- Дата и время прибытия (arrival_date)
- Дата и время отправления (departure_date)
- Порядковый номер (order) — числовое поле
- Кнопки «Сохранить» и «Отмена»

Можно частично заполнить поля для демонстрации, например:
- Название: «Стамбул, Площадь Султанахмет»
- Адрес: «Sultanahmet, Istanbul, Turkey»
- Широта: 41.0055
- Долгота: 28.9769

Форма должна демонстрировать пользовательский интерфейс для ввода данных об остановке маршрута.
