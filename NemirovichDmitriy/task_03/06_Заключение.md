# Заключение

В рамках курсового проекта разработана веб-платформа «Поехали!» для планирования совместных поездок. Выполнены все поставленные задачи: проведён анализ предметной области и сформулированы требования к системе, спроектирована модель данных с шестью основными сущностями и их связями, разработаны алгоритмы для ключевых операций, включая формирование списка доступных поездок, управление совместной работой с разграничением прав доступа, расчёт статистики по бюджету и механизм аутентификации на основе JWT с ротацией токенов.

Реализован полнофункциональный MVP-прототип, включающий серверную часть на Node.js с Express и клиентское приложение на React. Серверное приложение предоставляет REST API для работы с поездками, остановками, заметками и расходами, обеспечивает безопасную аутентификацию и авторизацию, выполняет валидацию данных с использованием Zod. Клиентское приложение реализует интуитивный пользовательский интерфейс с формами для создания и редактирования данных, автоматическим обновлением токенов доступа, корректной обработкой ошибок.

Система обеспечивает выполнение всех критериев приёмки MVP: пользователи могут регистрироваться и входить в систему, создавать поездки с указанием параметров, добавлять остановки к маршруту, вести заметки и учитывать расходы, приглашать других участников для совместной работы. Реализовано разграничение прав доступа: владельцы поездок управляют списком участников и могут удалять поездки, участники имеют доступ к содержимому и могут добавлять данные, администраторы обладают полным доступом ко всем ресурсам системы.

Применение современных технологий и инструментов обеспечило высокое качество кодовой базы и упростило процесс разработки. Использование TypeScript на клиенте и сервере позволило выявлять ошибки на этапе компиляции. Prisma ORM обеспечила типобезопасное взаимодействие с базой данных и автоматическую генерацию миграций. React с его компонентной архитектурой позволил создать переиспользуемые элементы интерфейса. Механизм JWT с разделением на access и refresh токены обеспечил баланс между безопасностью и удобством использования.

Тестирование подтвердило корректность работы основных сценариев. Проверено создание и редактирование всех типов сущностей, функционирование механизма совместной работы, правильность разграничения прав доступа, корректность расчёта суммарных расходов, работу автоматического обновления токенов при истечении access-токена.

В качестве направлений дальнейшего развития можно выделить следующие возможности. Интеграция с картографическими сервисами позволит автоматически строить маршруты между остановками и отображать их на интерактивной карте. Реализация системы уведомлений с использованием WebSocket или Server-Sent Events обеспечит информирование участников об изменениях в поездке в реальном времени [9]. Добавление функции экспорта данных о поездке в форматы PDF или Excel упростит подготовку отчётов и распечатку информации. Внедрение полнотекстового поиска с использованием возможностей PostgreSQL позволит быстро находить поездки и заметки по ключевым словам. Разработка мобильных приложений для iOS и Android расширит аудиторию и обеспечит доступ к системе в условиях путешествий. Реализация поддержки нескольких языков интерфейса сделает систему доступной для пользователей из разных стран [10].

Разработанная платформа демонстрирует применимость современного технологического стека для создания веб-приложений с акцентом на совместную работу пользователей. Проект может служить основой для коммерческого продукта или использоваться в образовательных целях как пример полнофункционального full-stack приложения с реализацией аутентификации, авторизации и работы с реляционной базой данных.
