# Реферат

Пояснительная записка содержит описание проектирования и разработки веб-платформы «Поехали!» — системы для планирования совместных поездок. Представлены результаты анализа требований, проектирования архитектуры системы, разработки алгоритмов обработки данных и реализации полнофункционального MVP-прототипа. Система реализована на базе современного технологического стека: клиентское приложение на React с использованием TypeScript, серверная часть на Node.js с фреймворком Express, база данных PostgreSQL с ORM-библиотекой Prisma [1]. Аутентификация построена на механизме JSON Web Tokens с ротацией токенов обновления. Архитектура системы предусматривает разделение на три уровня: уровень представления, прикладной уровень и уровень данных. Ключевые функциональные возможности включают создание поездок с маршрутами, управление остановками и расписанием, ведение бюджета и учёт расходов, совместное планирование с несколькими участниками, добавление заметок. Система обеспечивает разграничение прав доступа на уровне владельцев и участников поездок, а также ролевую модель «Администратор» и «Пользователь». Разработанная платформа позволяет пользователям эффективно планировать поездки, распределять бюджет, координировать действия участников и сохранять структурированную информацию о маршруте.

**Ключевые слова**: планирование поездок, веб-приложение, React, Node.js, PostgreSQL, REST API, JWT, совместная работа, маршруты, бюджет
