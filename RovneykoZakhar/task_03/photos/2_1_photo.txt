Для рисунка 2.1 – Диаграмма сущностей и связей:

Создать ERD-диаграмму (Entity-Relationship Diagram) базы данных системы. Диаграмма должна показывать 7 таблиц: User, Card, Deck, DeckCard, UserDeck, Review, Test. Для каждой таблицы отобразить основные поля (id, имена полей, типы данных). Показать связи между таблицами стрелками с указанием типа связи (один-ко-многим, многие-ко-многим). Использовать классический нотацию диаграмм баз данных (crow's foot notation или аналогичную).

Центральная сущность User должна иметь связи с Card (один пользователь — много карточек), Deck (один пользователь — много колод), Test (один пользователь — много тестов), UserDeck (один пользователь — много записей коллекции), Review (один пользователь — много оценок). Таблица DeckCard связывает Deck и Card (многие-ко-многим). Все связи должны быть чётко видны на диаграмме.
