Для рисунка 2.1 – Диаграмма сущностей и связей:

✅ ERD-диаграмма создана в файле 2_1_photo.png

Диаграмма содержит 7 таблиц базы данных системы:
- User: id, email, name, password, role, created_at
- Card: id, word, TranslitWord, examples, tags, UserId, created_at
- Deck: id, name, description, UserId, rating_avg, rating_count, created_at
- DeckCard: id, deck_id, card_id, added_at
- UserDeck: id, user_id, deck_id, is_favorite, created_at
- Review: id, deck_id, user_id, rating, reviewed_at
- Test: id, UserId, DeckId, score, total, created_at

Связи (crow's foot notation):
- User ||--o{ Card (один-ко-многим)
- User ||--o{ Deck (один-ко-многим)
- User ||--o{ UserDeck (один-ко-многим)
- User ||--o{ Review (один-ко-многим)
- User ||--o{ Test (один-ко-многим)
- Deck ||--o{ DeckCard (один-ко-многим)
- Card ||--o{ DeckCard (один-ко-многим)
- Deck ||--o{ UserDeck (один-ко-многим)
- Deck ||--o{ Review (один-ко-многим)
- Deck ||--o{ Test (один-ко-многим)
