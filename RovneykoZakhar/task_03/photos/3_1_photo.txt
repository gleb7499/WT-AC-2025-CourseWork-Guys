Для рисунка 3.1 – Архитектура системы:

✅ Диаграмма трёхзвенной архитектуры создана в файле 3_1_photo.png

Диаграмма содержит три основных блока:

1. 🖥️ Клиентская часть (Client / Frontend):
   - React + TypeScript SPA
   - Браузер пользователя

2. ⚙️ Серверная часть (Server / Backend):
   - FastAPI REST API
   - Обработка HTTP-запросов

3. 💾 База данных (Database):
   - SQLite DB
   - Хранилище данных

Стрелки взаимодействия между блоками:
- Клиент → Сервер: "HTTP/JSON + JWT Token"
- Сервер → Клиент: "JSON Response"
- Сервер → БД: "SQL Queries"
- БД → Сервер: "Data Results"
