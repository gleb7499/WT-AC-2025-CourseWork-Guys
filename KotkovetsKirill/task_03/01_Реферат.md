# Реферат

Настоящая пояснительная записка содержит описание курсового проекта по разработке веб-платформы «Учусь быстро» — системы мини-курсов с видеоуроками и автоматизированными тестами. Проект реализован на базе технологий Python и Flask с использованием реляционной базы данных SQLite.

В работе представлена постановка задачи с описанием функциональных и нефункциональных требований к системе, разработаны алгоритмы основных операций платформы, включая регистрацию и аутентификацию пользователей, управление курсами и уроками, отслеживание прогресса обучения и прохождение автоматизированных тестов. Описана архитектура системы, выбор технологического стека и реализация клиент-серверного взаимодействия.

Пояснительная записка включает описание моделей данных, алгоритмов обработки запросов, спецификации API и пользовательского интерфейса. Приведены инструкции по развертыванию и запуску приложения.

**Ключевые слова:** веб-разработка, Flask, Python, SQLite, мини-курсы, видеоуроки, автоматизированное тестирование, REST API, MVC-архитектура, аутентификация пользователей, отслеживание прогресса.
